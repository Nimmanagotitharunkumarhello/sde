# 📐 Lab Master Website

An interactive, responsive lab guide web application featuring UML diagrams, copy-ready code, searchable experiment cards, dark/light theme, progress tracking, and an integrated PDF document viewer for all lab manuals.

## ✨ Features
- **Interactive Experiment Cards**: Easily browse, expand, search, and track lab experiments.
- **Copy-Ready Code**: Instant copy button for lab Java codes.
- **Interactive PDF Resources ("Columns / Boxes")**: Click any box to open the PDF directly inside an embedded modal viewer or open in a new browser tab:
  - 📖 **Lab Manual (`SDE.pdf`)**: Complete lab manual, syllabus, diagrams, and Java code guide.
  - 📑 **Mini Lab Manual 3 (`Mini_Lab_Manual_3x3_Grid.pdf`)**: 3x3 Grid quick revision format and summary diagrams.
  - 📋 **Scenario PDF (`Scenario.pdf` / `all sereanio.pdf`)**: All problem scenarios, case studies, and questions.
- **In-Viewer PDF Switcher**: Quickly switch between all 3 PDFs directly inside the modal with one click.
- **Theme Support**: Clean modern light and dark modes.
- **Offline Capable**: Standalone and self-contained.
