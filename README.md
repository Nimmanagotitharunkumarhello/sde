# 📐 Lab Master Website

An interactive, responsive lab guide web application featuring UML diagrams, copy-ready code, searchable experiment cards, dark/light theme, progress tracking, and an integrated Lab Manual PDF viewer.

## ✨ Features
- **Interactive Experiment Cards**: Easily browse, expand, search, and track lab experiments.
- **Copy-Ready Code**: Instant copy button for lab codes.
- **Integrated PDF Manual**: View `manual.pdf` directly inside an embedded modal or open in a separate tab.
- **Theme Support**: Clean modern light and dark modes.
- **Offline Capable**: Standalone and self-contained.
