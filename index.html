OO Concepts (+ Java Demo)

▾
THEORY☕ JAVA

Aim

To study about the object-oriented concepts.

Core idea

Goal of OO: Reduce complexity of software development by keeping details (and changes to details) from spreading throughout the entire program.

Definitions

  • Client Code — the code that uses the classes under discussion
  • Coupling — code in one module depends on code in another; change in one forces rewrite/recompile of the other

The 4 Key Concepts (A-E-I-P)

Concept Meaning Key line
1. Abstraction Responsibilities (interface) ≠ implementation Class provides services via public interface; internals don't matter
2. Encapsulation Protect implementation from interference private access = wall around internals
3. Inheritance Share interface/implementation in related classes Functionality written once in base class, reused in descendants
4. Polymorphism Decouple client from exact class structure Client uses base-class interface; derived classes implement differently

Design thinking rules

1. Think of at least TWO reasonable ways to solve each design problem
2. "Reasonable" = "not obviously stupid"
3. Don't jump on the first design and hack it out
4. All designs are imperfect — they involve TRADE-OFFS
5. A good design is good in the MOST important ways
6. There may be more than one good design — different trade-offs
7. You can't choose intelligently if you thought of only ONE design

☕ Java Demo — OOPDemo.java (shows all 4 concepts)

// File: OOPDemo.java
abstract class Shape {                          // ABSTRACTION (interface only)
    abstract double area();
}

class Circle extends Shape {                    // INHERITANCE
    private double radius;                      // ENCAPSULATION (private data)
    Circle(double r){ radius = r; }
    double area(){ return 3.14 * radius * radius; }   // POLYMORPHISM (override)
}

class Rectangle extends Shape {
    private double l, b;
    Rectangle(double l, double b){ this.l = l; this.b = b; }
    double area(){ return l * b; }
}

public class OOPDemo {
    public static void main(String[] args){
        Shape[] s = { new Circle(5), new Rectangle(4, 6) };
        for(Shape x : s)                        // RUNTIME POLYMORPHISM
            System.out.println("Area = " + x.area());
    }
}
💡 Run output: Area = 78.5 and Area = 24.0. Point at the comments — each OOP concept is marked where it happens!

Study of UML Diagrams — Aim & Scope

▾
THEORY⭐ EXAM FAVORITE

Aim

General study of UML.

Why UML? (write this analogy)

Like architects' blueprints for buildings — the more complicated the system, the more critical the communication. UML = the software blueprint language giving analysts, designers, programmers a common vocabulary.

Key definitions

  • Model = abstraction of the underlying problem • Domain = actual world the problem comes from
  • Object = attributes (knows) + behaviors (does); attribute values = state
  • Class = "blueprint" for objects; wraps attributes + behaviors; objects = instances
  • UML notation: Unified Modeling Language • notations & conventions to model an application • universal standard for OO • does NOT specify methodology

The 9 kinds of UML diagrams

UML DIAGRAMS (9 kinds)
├── Class Diagram                    (static structure)
├── Use Case Diagram
├── Behavioral Diagrams
│    ├── Interaction Diagrams
│    │     ├── Sequence Diagram
│    │     └── Collaboration Diagram
│    ├── State Chart Diagram
│    └── Activity Diagram
└── Implementation Diagrams
      ├── Component Diagram
      └── Deployment Diagram

One-line definitions

Diagram Definition
Class Static structure; classes + relationships as a graph; 3 compartments: name / attributes / operations
Use Case Use cases (ellipses) in system boundary + actor associations
Sequence Behavior in time sequence; vertical = time, horizontal = objects; lifeline = object's existence
Collaboration Order of messages implementing an operation; objects, links, messages; object = state, behavior, identity
State Chart Dynamic behavior of one class; sequences of states, events, actions
Activity Sequence of activities in a process; special case of state machine; swim lanes = roles
Component Physical components; dependency graph; packages = class grouping
Deployment Runtime configuration; nodes connected by communication associations; 3D boxes

Notation cheat sheet

ACTOR = stick figure    USE CASE = ellipse    CLASS = rectangle (3 compartments)
GENERALIZATION ────▷ (hollow triangle → parent)     ASSOCIATION ──────►
INCLUDE/EXTEND - - -▷ (dashed)     START ●   END ◉
COMPONENT = box with tabs     DEPLOYMENT NODE = 3-D cube
Use case relations: Communication (line) | Uses (generalization) | Extends (dashed, does MORE)

// File: BookBank.java
import java.util.Scanner;

class Validity {
    int spinNo = 1234;
    boolean checkValidity(int pin){ return spinNo == pin; }
}

class Details {
    String bookName, author; int bcodeNo;
    Details(String b, String a, int c){ bookName = b; author = a; bcodeNo = c; }
    void displayDet(){ System.out.println("Code " + bcodeNo + " : " + bookName + " by " + author); }
}

class BookIssue {
    int noOfBooks = 0;
    boolean checkNoOfBooks(){ return noOfBooks < 3; }      // max 3 books per student
    void issueBooks(String b){
        noOfBooks++;
        System.out.println(">> Book ISSUED: " + b + " (books with student: " + noOfBooks + ")");
    }
}

class BookReturn {
    double fine;
    void returnDate(int due, int ret){
        if(ret > due){ fine = (ret - due) * 5.0;
            System.out.println(">> Late return! Fine = Rs." + fine); }
        else System.out.println(">> Returned on time. No fine.");
    }
}

class Students {
    String name, dept; int year;
    Students(String n, String d, int y){ name = n; dept = d; year = y; }
    void displayStudents(){ System.out.println(">> Student: " + name + " | " + dept + " | Year " + year); }
}

public class BookBank {
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        Validity v = new Validity();
        Details[] books = { new Details("Java", "Gosling", 101),
                            new Details("Networks", "Tanenbaum", 102),
                            new Details("SWE", "Pressman", 103) };

        System.out.println("===== BOOK BANK SYSTEM =====");
        System.out.print("Enter PIN: ");
        int pin = sc.nextInt();
        if(!v.checkValidity(pin)){ System.out.println("Invalid PIN! Access denied."); return; }
        System.out.println("Login successful.\n--- Book Bank Catalogue ---");
        for(Details d : books) d.displayDet();

        System.out.print("Enter book code to issue (101-103): ");
        int c = sc.nextInt();
        Details chosen = null;
        for(Details d : books) if(d.bcodeNo == c) chosen = d;
        if(chosen == null){ System.out.println("Invalid code!"); return; }

        BookIssue bi = new BookIssue();
        if(bi.checkNoOfBooks()){
            bi.issueBooks(chosen.bookName);
            new Students("Arun", "CSE", 3).displayStudents();
            System.out.print("Enter due date (day no): ");   int due = sc.nextInt();
            System.out.print("Enter return date (day no): "); int ret = sc.nextInt();
            new BookReturn().returnDate(due, ret);
            System.out.println(">> Book renewed. Thank you!");
        } else System.out.println(">> Limit reached (max 3 books)!");
    }
}

// File: CourseRegistration.java
import java.util.Scanner;

class CourseCatalog {
    int[]    courseId   = {501, 502, 503};
    String[] courseName = {"Java Programming", "Computer Networks", "Software Engineering"};
    double[] courseFee  = {1500, 1200, 1000};
    int[]    availSeats = {2, 0, 1};
    String[] eligibility = {"CSE", "ANY", "CSE"};

    void viewCourses(){
        System.out.println("--- Course Catalogue ---");
        for(int i = 0; i < courseName.length; i++)
            System.out.println(courseId[i] + " | " + courseName[i] + " | Rs." + courseFee[i]
                + " | Seats: " + availSeats[i] + " | Eligibility: " + eligibility[i]);
    }
    boolean isAvailable(int id){
        for(int i = 0; i < courseId.length; i++)
            if(courseId[i] == id) return availSeats[i] > 0;
        return false;
    }
    double feeOf(int id){
        for(int i = 0; i < courseId.length; i++)
            if(courseId[i] == id) return courseFee[i];
        return 0;
    }
    String criteriaOf(int id){
        for(int i = 0; i < courseId.length; i++)
            if(courseId[i] == id) return eligibility[i];
        return "ANY";
    }
}

class ReserveCourse {
    int stId, regId = 5001; String courseId; double amtPaid;
    boolean checkEligibility(String dept, String criteria){
        return criteria.equals("ANY") || criteria.equalsIgnoreCase(dept);
    }
    void confirmRegistration(String sName, int id, String cId, double paid){
        stId = id; courseId = cId; amtPaid = paid;
        System.out.println(">> Registration CONFIRMED! Reg No: " + regId + " | " + sName
            + " | Course " + cId + " | Paid Rs." + paid);
        System.out.println(">> Acknowledgment sent to student and registrar.");
    }
}

public class CourseRegistration {
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        CourseCatalog cat = new CourseCatalog();
        System.out.println("===== ONLINE COURSE REGISTRATION =====");
        System.out.print("Enter student name: ");            String name = sc.nextLine();
        System.out.print("Enter department (CSE/ECE...): "); String dept = sc.nextLine();
        System.out.print("Login - enter password: ");        sc.nextLine();
        System.out.println("Login successful.");
        cat.viewCourses();

        System.out.print("Enter course id to register: ");
        int cid = sc.nextInt();
        if(!cat.isAvailable(cid)){ System.out.println(">> Course NOT available (no seats)."); return; }
        ReserveCourse rc = new ReserveCourse();
        if(!rc.checkEligibility(dept, cat.criteriaOf(cid))){
            System.out.println(">> Not eligible for this course."); return;
        }
        System.out.print("Course available! Enter amount to pay (Rs." + cat.feeOf(cid) + "): ");
        rc.confirmRegistration(name, 101, "" + cid, sc.nextDouble());
    }
}

// File: ATMBank.java
import java.util.Scanner;

abstract class Account {                        // ENCAPSULATION (private balance)
    long accountNo; String type; private double balance;
    Account(long no, String t, double b){ accountNo = no; type = t; balance = b; }
    void debit(double amt){
        if(amt > balance){ System.out.println(">> Insufficient balance! (Rs." + balance + ")"); return; }
        balance -= amt; System.out.println(">> Debited Rs." + amt + " | Balance: Rs." + balance);
    }
    void credit(double amt){ balance += amt; System.out.println(">> Credited Rs." + amt + " | Balance: Rs." + balance); }
    void showBalance(){ System.out.println(">> A/C " + accountNo + " (" + type + ") Balance: Rs." + balance); }
}
class SavingsAccount extends Account {          // INHERITANCE (as in class diagram)
    SavingsAccount(long no, double b){ super(no, "Savings", b); }
}
class CurrentAccount extends Account {
    CurrentAccount(long no, double b){ super(no, "Current", b); }
}

class DebitCard {
    long pin = 1111;
    boolean access(long p){ return pin == p; }
}

class ATMTransaction {                          // parent of all transactions
    static int transactionID = 1000;
    ATMTransaction(String type){
        transactionID++;
        System.out.println(">> Txn #" + transactionID + " : " + type);
    }
}
class Withdrawal extends ATMTransaction {
    double amount;
    Withdrawal(double amt){ super("WITHDRAWAL"); amount = amt; }
    void withdraw(Account a){ a.debit(amount); }
}
class Deposit extends ATMTransaction {
    double amount;
    Deposit(double amt){ super("DEPOSIT"); amount = amt; }
    void deposit(Account a){ a.credit(amount); }
}
class Transfer extends ATMTransaction {
    double amount;
    Transfer(double amt){ super("TRANSFER"); amount = amt; }
    void transfer(Account from, Account to){ from.debit(amount); to.credit(amount); }
}
class Query extends ATMTransaction {
    Query(){ super("BALANCE QUERY"); }
    void processing(Account a){ a.showBalance(); }
}
class PINValidation extends ATMTransaction {
    PINValidation(){ super("PIN VALIDATION"); }
    boolean pinChange(long entered, long actual){ return entered == actual; }
}

public class ATMBank {
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        SavingsAccount savings = new SavingsAccount(1001, 5000);
        CurrentAccount current = new CurrentAccount(2002, 10000);
        DebitCard card = new DebitCard();

        System.out.println("===== ATM MANAGEMENT SYSTEM =====");
        System.out.print("Insert card... Enter PIN: ");
        if(!new PINValidation().pinChange(sc.nextLong(), card.pin)){
            System.out.println(">> Invalid PIN! Card ejected."); return;
        }
        System.out.println(">> PIN OK. Welcome!");
        int opt;
        do {
            System.out.println("\n1.Withdraw  2.Deposit  3.Transfer  4.Balance  5.Exit");
            System.out.print("Choose option: ");
            opt = sc.nextInt();
            switch(opt){
                case 1: System.out.print("Amount: ");
                        new Withdrawal(sc.nextDouble()).withdraw(savings); break;
                case 2: System.out.print("Amount: ");
                        new Deposit(sc.nextDouble()).deposit(savings); break;
                case 3: System.out.print("Amount (Savings->Current): ");
                        new Transfer(sc.nextDouble()).transfer(savings, current); break;
                case 4: new Query().processing(savings);
                        new Query().processing(current); break;
                case 5: System.out.println(">> Take cash & receipt. Thank you!"); break;
                default: System.out.println(">> Invalid option!");
            }
        } while(opt != 5);
    }
}
